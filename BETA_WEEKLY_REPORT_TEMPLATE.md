# Тижневий beta-звіт — тиждень N (дати)

## 1. Аудиторія
Запрошено / зареєстровано / активовано / повернулось (W1). Джерело: Admin → Analytics
(`beta_metrics`), analytics_events.

## 2. Використання
Контент (перегляди/збереження) · Network (пошуки/перегляди профілів-організацій) ·
Opportunities (published/views/applications) · Applications (submitted/contacted/accepted) ·
Introductions (submitted/sent/outcomes/overdue) · Events (published/registrations/attendance).

## 3. Цінність
Підтверджені business outcomes (тип/модуль/cohort) · зустрічі · контакти · accepted
Applications · сигнали співпраці.

## 4. Проблеми
Багі (P0–P3) · drop-offs воронки · модерація · privacy · support.

## 5. Експерименти
Для кожного: гіпотеза · аудиторія · метрика · результат · рішення.

## 6. Наступний тиждень
Продуктові пріоритети · операційні пріоритети · розширення cohort · контент-план.
